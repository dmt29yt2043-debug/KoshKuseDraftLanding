# KOSH KUSE — черновик лендинга

Одностраничный лендинг: манифест, состав подписки, четыре тарифа и заявка.
`index.html` самодостаточен — картинки вшиты как data URI, внешних запросов нет.
Открывается двойным кликом, без сборки и без интернета.

**Живая версия:** https://kosh-kuse.srv1362562.hstgr.cloud
Закрыта от поисковиков (`X-Robots-Tag: noindex` + `robots.txt`), потому что бренд ещё не запущен.

## Как править

Не редактируйте `index.html` руками — там base64-блобы. Правьте исходник и пересоберите:

```bash
cd src && python3 build.py
```

- `src/landing.src.html` — разметка и стили, картинки помечены плейсхолдерами `__IMG_*__`
- `src/assets/*.jpg` — фотографии, вырезанные из брендовой деки
- `src/build.py` — подставляет картинки в плейсхолдеры и кладёт результат в `index.html`

## Обновить живую версию

```bash
scp -i ~/.ssh/github_key -P 2222 index.html root@187.77.18.20:/var/www/kosh-kuse/index.html
```

## Шрифт

Основной гротеск — **Values Sans**. Файлов в репозитории нет: шрифт коммерческий,
для веба нужна отдельная лицензия. Сейчас он стоит первым в стеке и подхватывается,
если установлен у зрителя; иначе страница откатывается на системный гротеск.

Чтобы подключить по-настоящему: положить лицензированные `.woff2` в `fonts/`
и раскомментировать блок `@font-face` в начале `src/landing.src.html`.

Заголовки набраны антиквой — по брендбуку «дом — спокойная антиква, движение CLM — жёсткий гротеск».

## Чего здесь нет

Финмодель, аудит и производственный бриф намеренно не входят в репозиторий —
он публичный. Они остаются в рабочей папке `Kosh-Kuse-Finance`.

## Не доделано

Форма заявки никуда не отправляет данные: по нажатию показывает подтверждение
на месте. Нужно подключить к CRM, боту или форм-сервису.
