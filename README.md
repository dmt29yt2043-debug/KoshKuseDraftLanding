# KOSH KUSÉ — сайт клуба заботы о кошках

Mobile-first сайт в светлой айдентике: прелоадер, сцены на прокрутке, анкета «Вступить в клуб» с приёмом заявок.

**Живая версия:** https://kosh-kuse.187-77-18-20.sslip.io/
(старый адрес `kosh-kuse.srv1362562.hstgr.cloud` у части провайдеров режется по домену — давайте ссылку sslip.io).
Сайт закрыт от поисковиков (`noindex` + `robots.txt`): бренд ещё не запущен.

## Версии

- **v2** — ветка `site-v2`, живёт в корне сайта. Её ведёт Вадим.
- **V3** — ветка `site-v3`, черновик на https://kosh-kuse.187-77-18-20.sslip.io/v3/ . Сделана по аудиту лендинга от 11.10.2026
  (`docs/audit-2026-10-11.txt`): приглашение основателей, честное разделение «доступно / пилот / следующий этап»,
  роль первых участников и первый месяц, команда, правила приглашения, короткая заявка. Каркас и решения — `docs/v3-blueprint.md`,
  база фактов из бренд-бука, тизеров и таблицы продукта — `docs/v3-facts.md`. Чего в источниках нет, на странице отмечено
  видимыми пометками `<mark class="todo">…</mark>` — их снимает владелец, подставляя факты.

## Что где

```
site/                сайт
  site.src.html      разметка и стили (шаблон с плейсхолдерами {{img:…}}, <!--…-->)
  script.js          вся анимация и интерфейс: прелоадер, сцены, меню, анкета
  build.py           сборка → site/dist/
  img/               готовые фото (WebP, по 2–3 ширины)
  forms/app.py       приём анкет (Python, только стандартная библиотека, SQLite)
  forms/*.service    systemd-юнит для сервера
  cdp.mjs            headless Chrome для проверки: node cdp.mjs plan.json
  serve.mjs          локальный сервер со сжатием, как на проде
src_fonts/           шрифты (Cormorant Garamond — OFL; Value Sans Pro — НЕ в репозитории)
logo/                векторизованный логотип: кошка, надпись, композиция
tools/               подготовка фото (process_images.py, selection_*.json), векторизация логотипа
legacy/              первый, тёмный черновик лендинга (больше не используется)
```

## Собрать и посмотреть

```bash
cd site
python3 build.py              # → site/dist/index.html, dist/img, dist/fonts
node serve.mjs 8766           # http://127.0.0.1:8766  (Node 22+)
```

**Шрифт Value Sans Pro коммерческий** — в публичный репозиторий не кладём. Файлы `ValueSansPro-400/500/700-normal.woff2`
передаются отдельно (попросите у Максима) и кладутся в `src_fonts/`. Без них сборка не падает — сайт возьмёт системный гротеск.

Параметры адреса: `?nointro` — без прелоадера; `?site` — на десктопе сам сайт вместо стенда; `?stand` — стенд на телефоне.

Анкета локально — поднять приёмник рядом (serve.mjs сам пробрасывает `/api` и `/admin`):

```bash
cd site/forms && KK_PORT=8391 python3 app.py     # база — в site/forms/state/
```

## Как устроено

- **Прелоадер** — решение в `<head>` (каждое открытие, кроме «назад» и `?nointro`; при «Уменьшении движения» — спокойная версия).
  Рисунок кошки стартует маленьким скриптом сразу после разметки заставки (`window.KKintro`), не дожидаясь страницы;
  финал (надпись перелетает в шапку) регистрирует `script.js`. После заставки страница всегда сверху.
- **Сцены прокрутки** — один rAF-цикл в `script.js`: арка героя, манифест по словам, стопка карточек продукта,
  «1+1», карточка-история «Здоровье» (листается и свайпом вбок, и прокруткой вниз — синхронно), «живой» телефон приложения,
  финал с выглядывающей кошкой. Заголовки поднимаются из-под маски по словам.
- **Картинки и шрифты** в HTML идут с `?v=<хеш>` — новая картинка с тем же именем не застрянет в кэше телефона.
- **Режимы:** телефон/планшет — сам сайт; десктоп с мышью — стенд с переключателем «Мобильная · Десктоп · Все экраны».
- **Без JS и при «Уменьшении движения»** всё содержимое видно, анимации отключены.

## Проверка перед выкладкой

`node site/cdp.mjs plan.json` — план из шагов (`viewport`, `goto`, `wait`, `scroll`, `click`, `eval`, `shot`,
`throttle` — медленная сеть, `nojs`). Минимум: 390×844, 375×667, 844×390 (телефон боком), 1440×900 и стенд;
`?nointro`, «Уменьшение движения», без JS. Время на медленной сети мерить `eval`-ом из страницы — скриншоты во время загрузки врут.

## Выкладка

На VPS (Caddy): содержимое `site/dist` (`index.html`, `img/`, `fonts/`) → `/var/www/kosh-kuse/v2/`, `robots.txt` оставить.
Приёмник анкет — systemd `kosh-kuse-forms` (127.0.0.1:8391, база `/var/lib/kosh-kuse-forms/`), Caddy проксирует `/api/*`
и закрывает паролем `/admin*` (таблица заявок, статусы, выгрузка в Excel).
**Доступы к серверу и пароль от таблицы заявок в репозитории не хранятся** — их передаёт Максим лично.

## Бренд — коротко

- Палитра: молочный `#F7F4EB` и лён `#E8DFC9` — основа (85–90%), тёмный `#2B2A26`/`#5A5249` — 5–10%,
  винный `#4A1F27` — только акцент (3–5%: основная кнопка, ссылки, выбранное, логотип). Золото, олива, охра — нельзя.
- Логотип — только надпись KOSH KUSÉ или кошка вместе с надписью. Кошку отдельно не используем.
- Голос: о кошке — «она»/по имени; без «питомец», «хозяин», «вкусняшки», «скидка/акция», уменьшительных и восклицаний;
  не давить на вину и не пугать.
- Фото: светлые интерьеры, лён, дуб, травертин; документальная плёночная съёмка, в каждом кадре своя кошка.
  Сейчас все фото сгенерированы в ChatGPT — перед запуском нужна живая съёмка.

## Открытые вопросы

- «Влажный корм» в карточке рациона спорит с «еда, а не корм».
- Видео основателя и видеоистории участниц — заглушки; ссылки в подвале — заглушки; счётчик «312» — статичный.
- По 152-ФЗ данные заявок граждан РФ нужно хранить на сервере в России — текущий VPS годится только для теста.
- Нужна политика обработки персональных данных (ссылка у галочки согласия в анкете).
